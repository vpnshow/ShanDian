## 闪电鼠(ShanDian)VPN线路与使用特点

**闪电鼠(ShanDian)** 于 **2024 年**开始运营，采用 **VLESS 协议**，以低价小流量年付方案面向轻度用户，也提供更高流量的常规周期套餐。

- **线路类型**：限时钜惠小包标注 **IPLC 专线**；轻快、疾速、雷霆三款常规套餐标注 **IEPL 专线**。
- **倍率与设备**：当前收录的四款套餐均标注 **1 倍率、不限设备连接数、不限速**；实际体验仍受本地网络、节点负载与使用时段影响。
- **速率说明**：小包与雷霆套餐标注最高 **2.5Gbps**，可作为套餐规格参考，日常连接速度以实际使用情况为准。
- **流量重置**：四款套餐均标注**每 30 天重置流量**，其中小包明确从购买日起计算；流量额度按月提供，不是整个付款周期共用一份。
- **客户端与订阅**：可使用自研客户端；导入第三方客户端时，需**联系官方客服获取订阅导入方式**，并确认协议及订阅格式兼容性。
- **AI 与流媒体**：品牌资料称覆盖常见 AI 工具及流媒体场景，具体平台与地区的可用情况以节点实际检测为准。

## 闪电鼠(ShanDian)VPN套餐与使用常见问题

<a id="shandian-annual-price"></a>

### 闪电鼠 ¥5.60/月是什么价格？

这是限时钜惠小包**符合新人 `sd88` 7 折条件并在结算时生效后的年付折合价**：原价 ¥96/年，折后一次支付 ¥67.20/年，除以 12 个月为 ¥5.60/月。它不是套餐标价，也不支持按 ¥5.60 月付；60GB 是每月额度，不是全年总流量。

<a id="shandian-coupon-guide"></a>

### sd88 与 eoth01 有什么区别，可以叠加吗？

`sd88` 是**新用户购买季付及以上享 7 折**的优惠码；`eoth01` 是**专属 8 折码**，具体适用范围需在结算页核对。两者不默认叠加。以小包为例，8 折生效时为 ¥76.80/年，折合 ¥6.40/月；实际支付以结算页接受的优惠码及最终金额为准。

<a id="shandian-subscription-guide"></a>

### 第三方客户端的订阅怎么导入？

闪电鼠提供自研客户端。需要导入第三方客户端时，请**联系官方客服获取订阅导入方式**，并说明自己的系统与客户端。确认适配后，可参考[Clash Verge Rev 教程](https://eoht.net/serve/antiwall/clash-verge-rev)、[Shadowrocket 教程](https://eoht.net/serve/antiwall/shadowrocket)或[客户端教程汇总](https://eoht.net/serve/antiwall/summary)完成配置。

### 闪电鼠有不限时套餐吗？

当前收录的四款套餐均按周期订阅、每 30 天重置流量，暂未收录不限时套餐。购买前可在官方面板查看最新套餐与流量规则。
